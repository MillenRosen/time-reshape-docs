# 三分钟入门

先体验一个问答，再看一段预计算复原，就能熟悉时光重塑的主要用法。

## 第一步：打开应用

- **安卓手机**：从[安装与下载](downloads.md)取得 APK，安装后打开“时光重塑”。
- **iPhone 或暂时不安装**：用浏览器打开[网页预览]({{ preview_url }})。iPhone 目前使用 Safari 体验，尚无可直接安装的 IPA。

当前体验服务有独立的访问口令，由项目提供者告知。网页按提示输入；安卓在 **我的 → 服务连接** 输入口令，点击 **保存并连接**。看到“问答已连接”后即可提问。复原页会单独显示复原服务状态。

:::{tip}
服务访问口令与个人账号密码是两回事。新时光账号的初始密码是 `123456`，它不能用来代替服务访问口令。详细说明见[连接服务](guide/connection.md)。
:::

## 第二步：问圆圆一个问题

1. 点击首页 **问一问历史**，进入一个新对话。
2. 在输入框填写“大水法由哪里供水？”，或点选推荐问题。
3. 点击发送，等待检索和回答。
4. 阅读回答正文、圆明园故事和资料来源。右上角 **历史** 可以找回已保存的问答。

首页的推荐问题会直接发起提问；“问一问历史”只打开新对话，不会自动替你选择问题。

## 第三步：看一段复原示例

1. 点击底部 **遗迹影像**，保持 **云端示例** 选中。
2. 选择一段大水法示例，点击 **观看复原示例**。
3. 在结果区域点击播放。
4. 选择 **上下分屏** 看原片与复原同帧对照，或选择 **透明叠加** 拖动浓度滑块。

示例已经提前计算，无需现场等待复原算法运行；视频文件本身仍需通过网络加载。网络较慢时先使用 **流畅 · 省流量** 画质。

## 第四步：记住你的账号

打开 **我的 → 我的时光账号**，复制并保管登录用户名。首次成功连接服务后会自动分配账号，你可以直接体验，再设置昵称和头像。

建议在 **修改密码** 中设置个人密码。以后在另一台设备打开应用，连接服务后，通过 **切换账号** 输入原登录用户名和密码，找回资料与历史。

## 四个页面分别做什么？

| 页面 | 主要用途 |
| --- | --- |
| 首页 | 新建问答、选择推荐问题、进入遗迹影像 |
| 遗迹影像 | 观看云端示例、上传视频、实时相机、查看复原记录 |
| 史实问答 | 自由提问、阅读依据与来源、新对话、历史记录 |
| 我的 | 昵称与头像、账号密码、同步、实时方案、服务连接 |
