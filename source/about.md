## 范围与边界

史实问答基于现有资料，引用与推定需结合阅读。遗迹复原用于模型的视觉呈现，当前地图覆盖范围有限；它不能代替考古研究、文物鉴定或精密测绘。

安卓支持范围、iPhone 工程与实体设备验收状态见[安装与下载](downloads.md)。云端服务可用性和临时入口地址可能随部署变化，以项目提供者的当前通知为准。

## 文档结构参考

手册参考 [TNLearn 文档项目](https://github.com/MillenRosen/tnlearn_doc)的 Sphinx、MyST Markdown 与 Read the Docs 主题组织方式。正文、配色和页面组件按时光重塑的使用场景重新编写。

文档是独立项目，构建时不需要启动问答模型、复原 GPU 服务或读取任何用户凭据。网站资源随文档发布，页面不依赖外部字体或远程界面图片。

维护者可在仓库根目录的 `README.md` 和 `DEPLOYMENT.md` 中查看本地构建、检查与 Read the Docs 发布方法。
