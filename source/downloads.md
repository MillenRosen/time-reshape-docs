## 安卓安装步骤

1. 在手机浏览器打开上方下载页，下载 `{{ apk_name }}`。
2. 在浏览器下载列表或文件管理器中打开 APK。
3. 如果系统询问安装来源，按系统提示允许当前浏览器或文件管理器安装该文件。
4. 打开 **时光重塑**，应用会自动配置默认服务并完成访问验证，看到“问答已连接”即可开始使用。

已有同签名旧版时，直接覆盖安装即可保留应用数据。**升级前不需要卸载或清除数据**；建议先在“我的”记下登录用户名，以便跨设备或重新安装后恢复账号。

### 在应用中更新

v0.14.0 起，打开 **我的 → 检查更新**。发现新版后点击 **下载并安装**，可查看下载进度或取消。下载完成并通过校验后，应用会打开安卓系统安装界面。

首次使用时，系统可能要求允许“时光重塑”安装应用。开启后返回应用，再按系统提示确认安装；如果取消了，可以点击 **继续安装**。已完整下载的安装包可在重新打开应用后继续安装。下载中断或应用进程被系统结束时，需要重新下载。

**v0.13.0 及更早的本地打包版本没有此功能，请先从本页下载新版，覆盖安装一次。** 无需卸载，之后即可在应用中更新。网页上的下载按钮仍用于首次安装。

### 系统要求

| 项目 | 要求或说明 |
| --- | --- |
| 安卓系统 | Android 6.0 及以上 |
| 系统网页组件 | Android System WebView / 对应系统网页组件 105 或更新 |
| 网络 | 问答、账号同步、复原与在线播放需要联网 |
| 相机 | 使用实时相机时才需要相机权限 |
| 手机协同 | 首次准备约 33 MB 模型与跟踪工具，之后可复用缓存 |

最低系统版本不代表所有设备都已完成实机验收。实时体验还取决于系统网页组件、设备性能、温度和网络情况。

## iPhone 与 iPad

当前可用 Safari 打开[网页预览]({{ preview_url }})，使用问答、云端示例和设备支持的相机功能。功能可用性与浏览器编解码、相机和图形能力有关。

下载页另提供 **v0.10.2 Xcode 工程 ZIP**，仅供开发者在 Mac 上继续编译和签名。它不是安装包，不能直接安装到 iPhone；目前尚未发布可安装的 IPA 或 TestFlight 版本。

## 下载地址打不开

本手册的下载与预览链接使用固定导航地址，每次点击都会查询服务器记录的最新入口，再前往对应页面。临时域名更换后，不需要更新或重新下载手册；PDF 中的链接也使用同一导航地址。

加速隧道重连时若尚无已注册入口，导航会转到备用服务。若当前加速地址仍打不开，可直接尝试[备用下载入口]({{ backup_download_url }})。固定导航服务也需要网络可达；若两个入口都不可用，请联系项目提供者。

v0.12.3 起，安卓会自动处理默认入口失效；必要时在 **我的 → 服务连接** 点击 **重新自动连接** 即可。旧 APK 请先覆盖安装新版。
