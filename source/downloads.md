## 安卓安装步骤

1. 在手机浏览器打开上方下载页，下载 `{{ apk_name }}`。
2. 在浏览器下载列表或文件管理器中打开 APK。
3. 如果系统询问安装来源，按系统提示允许当前浏览器或文件管理器安装该文件。
4. 打开 **时光重塑 → 我的 → 服务连接**，选择加速入口，输入服务访问口令并保存。

已有同签名旧版时，直接覆盖安装即可保留应用数据。**升级前不需要卸载或清除数据**；建议先在“我的”记下登录用户名，以便跨设备或重新安装后恢复账号。

### 系统要求

| 项目 | 要求或说明 |
| --- | --- |
| 安卓系统 | Android 6.0 及以上 |
| 系统网页组件 | Android System WebView / 对应系统网页组件 105 或更新 |
| 网络 | 问答、账号同步、复原与在线播放需要联网 |
| 相机 | 使用实时相机时才需要相机权限 |
| 手机协同 | 首次准备约 33 MB 模型与跟踪工具，之后可复用缓存 |

最低系统版本不代表所有设备都已完成实机验收。实时体验还取决于系统网页组件、设备性能、温度和网络情况。

### 本版修复了什么？

v0.11.2 修复云端实时相机的 H.264 首帧停滞，并在编码不兼容时自动尝试 VP8。它保留 v0.11.1 的首次启动授权修复。更新服务器网页不会自动修改手机中旧 APK 的界面代码，安卓用户需要安装新版。

## iPhone 与 iPad

当前可用 Safari 打开[网页预览]({{ preview_url }})，使用问答、云端示例和设备支持的相机功能。功能可用性与浏览器编解码、相机和图形能力有关。

下载页另提供 **v0.10.2 Xcode 工程 ZIP**，仅供开发者在 Mac 上继续编译和签名。它不是安装包，不能直接安装到 iPhone；目前尚未发布可安装的 IPA 或 TestFlight 版本。

## 下载地址打不开

加速入口使用临时域名，地址可能更换。先尝试[备用下载入口]({{ backup_download_url }})。若两个入口都不可用，请联系项目提供者获取当前地址和访问口令。

已安装的安卓用户还可在 **我的 → 服务连接** 点击 **加速入口失效时，查找新入口**，找到后再点击 **保存并连接**。
