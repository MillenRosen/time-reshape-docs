# 版本与更新

本手册对应 **时光重塑 v{{ version }} / Android build {{ build }}**。网页与 APK 共享主要界面，但 APK 把代码保存在本机，网页更新后旧 APK 不会自动变成新版。

## v0.14.0 · 应用更新版

2026-11-04 · Android build 22

- “我的”新增检查更新、下载进度、取消和继续安装。
- 安装前核对文件大小、SHA-256、包名、版本和签名；校验通过后打开系统安装界面。
- 首次允许应用安装来源后，返回即可继续安装；同签名覆盖升级保留数据。
- v0.13.0 及更早的本地打包版本需手动覆盖安装新版一次，以启用更新功能。

已完成 Android 10 模拟器下载与安装流程验证、浏览器交互和发布文件校验；实体手机仍需实际体验确认。

## v0.13.0 · 渐显复原版

- 新增渐显复原与直接复原选择，应用于云端示例、上传视频和实时相机。
- 建筑在确认定位后分区浮现，约 5 秒完成；浓度与大屏小窗仍可独立调整。
- 五个云端示例提供预计算渐显版本，旧记录继续可看，下载保留渐显过程及所选浓度。
- 实时失锁时隐藏复原，恢复定位后直接显示完整模型；编码兼容切换不会重新开始开场。

Android build 21 沿用原签名，可覆盖安装。网页与 APK 使用同一套界面资源。已进行服务端渲染、浏览器及打包验证；实体安卓/iPhone 的温控与长时间帧率仍待实机验收。

## v0.12.3 · 自动连接

2026-11-04 · Android build 20

- 首次打开自动选择可用入口并完成默认访问验证，无需填写网址和默认口令。
- 入口失效、会话过期时尝试自动恢复；断网后恢复联网可以重试。
- 自定义服务器和明确指定的备用入口保留原选择，手动配置收进展开设置。
- 页面本地显示，连接准备完成后再发送问答与账号请求。

## v0.12.1–0.12.2 · 下载与小窗优化

2026-11-04 · Android build 18–19

- 下载按当前预览浓度导出，100% 不再下载半透明视频。
- 大屏小窗导出完整复原大屏；原片小窗缩小并移至右上角。

## v0.12.0 · 全屏观影

2026-11-03 · Android build 17

- 成片播放与实时相机进入全屏预览，操作集中在画面边缘。
- 大屏小窗取代上下分屏，大屏固定显示 100% 复原，小窗显示同帧原片。
- 默认等比例铺满，可切换完整画面；支持横竖屏与隐藏控件。
- 退出成片预览会暂停并保留进度，退出实时预览会停止相机。
- 网页同步更新，安卓沿用原包名与签名，可覆盖安装。

## v0.11.2 · 云端画面恢复

2026-10-23 · Android build 16

- 修复云端相机 H.264 首帧停滞，启用低延迟解码。
- 编码不兼容时自动尝试 VP8，网络连接失败单独提示。
- 调整等待文案，完善停止相机后的连接和资源清理。
- 网页同步更新，沿用安卓包名和签名，可覆盖安装。

已在实际 GPU 服务、Chrome 视频编解码及 Android 转发层验证。Android 正式包启动和 Activity 重建测试通过；这些结果不等于所有安卓实体设备和移动网络均已验收。

## v0.11.1 · 启动修复

2026-10-23 · Android build 15

修复首次打开出现“此连接仅供本机应用使用”的问题。补充本机授权、WebView 首次导航和 Activity 重建验证。

## v0.11.0 · 完整界面本地打包

2026-10-22 · Android build 14

把完整页面、圆圆图片和界面素材打包进 APK，保留原有网页风格；问答与复原连接可配置的服务器。增加流畅视频画质，保留高清选项。该早期包的启动问题已在后续版本修复，不建议继续安装。
