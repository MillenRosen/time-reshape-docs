# 服务台与资源管理

服务台供服务器维护者使用，用于启动、停止软件计算，以及查看 CPU、内存和 GPU 资源。它与手机里的“我的”、网页模型管理后台是三个不同入口。

## 连接服务台

在已配置的电脑上运行服务台启动器，完成 SSH 登录后，浏览器打开 `http://127.0.0.1:18080/`。这是**电脑通过 SSH 转发的本机地址**，不是可发给手机直接访问的公网网址。

原服务器使用既有启动器。另建服务器时，按[部署与交付文件](deployment.md)配置自己的 SSH 主机和端口；不要复制其他服务器的私有凭据。

## 三个主要操作

| 操作 | 适用情况与影响 |
| --- | --- |
| 启动软件服务 | 开始提供问答、复原与网页服务；模型加载期间等待就绪 |
| 暂停计算 · 释放显存 | 暂时不用软件计算时，停止问答、复原与实验，保留网页和管理入口 |
| 停止实验服务 | 保留正式应用，仅关闭研究、评测与开发工具 |

原服务器的“启动软件服务”同时维护已配置的公网通道；参赛迁移包的精简服务台仅管理包内网关、问答和复原三个核心服务，HTTPS 入口需另行配置。

暂停计算后，**即使网页仍能打开，也不能继续发起问答、读取新的复原记录或请求影像服务**。已经缓冲的画面可能短暂继续播放。恢复时点击启动，并分别确认问答与复原就绪。

单个服务也可独立启动或停止。控制台自身不提供停止自己的按钮，以免失去控制入口。

## 调整 GPU 使用范围

1. 先查看每张卡的总显存、已用显存和当前分配。服务器总量可能包含其他任务，不能只看本软件用量。
2. 选择至少两张有足够空间的 GPU；如必要，可扩大范围。
3. 点击 **应用显卡范围**，等待操作结束并核对服务状态。
4. 恢复后用一个问答和一段示例确认功能，再进行实时相机或上传测试。

以控制台显示的**当前分配**为准，不固定要求 GPU 0、2 或 GPU 2、3。扩大范围不等于自动提高问答速度，也不会自动创建多份问答大模型。

变更会重启正在运行的计算服务，当前问答和实时相机可能中断。迁移前会检查可用空间；空间不足时拒绝迁移，其他用户的任务不会被停止或移动。共享服务器仍可能在检查后出现新的资源竞争。

## 读懂资源监控

“资源脉搏”约每 5 秒采样一次，可查看最近 1、5、10 分钟的 CPU、内存、GPU 利用率与显存趋势，以及温度、功耗、网络和磁盘信息。悬停曲线可查看某次采样。

“进程占用”显示受管服务及子进程的 CPU、内存、显存和进程数。CPU 按整机总容量归一化；多个进程的 RSS 相加可能重复计算共享内存，不能直接等同服务器总内存。

历史采样仅保留在服务台进程内存中，重启后重新累计。首次缺少速率基线或 GPU 采样失败时可能显示“—”，不代表用量为零。

## 实验工具如何选择

原服务器的 15 项实验与开发工具已分组：

| 分组 | 工具与使用建议 |
| --- | --- |
| 当前开发 · 4 项 | 三维工作区、渐显效果工作区、性能诊断、前端预览；仅在相应任务需要时启动 |
| 辅助工具 · 3 项 | 定位回放、端云历史对照、掩码标注；按需打开 |
| 暂时搁置 · 8 项 | 旧多 GPU、视觉 v1–v3、编码、WebRTC、旧遮挡、TRELLIS；保留资料，不从页面启动 |

性能诊断属于独立诊断快照，其历史测试结果不是当前手机的实时性能保证。渐显效果工作区用于观察效果，与手机的正常播放界面不同；切后台暂停、返回续播，视频模式随实际帧推进，三维模式在低帧率时延长播放以便看清过程。

精简迁移包没有完整研究工作区，不会因为导入服务台源码就自动获得上述所有实验入口。

## 启动器 90 秒超时怎么办？

这不是显存不足的唯一表现，也不能据此直接判断 GPU 故障。旧版曾因健康检查版本判断不匹配而超时，服务台 v2.1.1 起已兼容旧启动器。

如果仍出现，先检查 SSH 是否成功登录、端口 18080 是否正确转发、服务器上的服务台进程是否运行，以及本机端口是否被其他程序占用。只有控制台能打开、计算服务启动失败时，再结合显存和具体日志排查。
