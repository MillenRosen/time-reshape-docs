# 史实问答

圆圆陪你从史料中寻找答案。可以询问圆明园的建筑、历史、园林和文物，也可以直接选择推荐问题。

```{figure} ../_static/images/app-chat.webp
:alt: 史实问答首页，中央的圆圆欢迎形象与底部输入框
:class: app-shot
:width: 300px

从输入框开始一段新的问答。
```

## 开启一段对话

- 在首页点击 **问一问历史**：进入空白新对话。
- 点击底部 **史实问答**：返回当前对话。
- 点选首页或问答页的推荐问题：立即发送对应问题。
- 已经有内容时，点击右上角 **新对话**：从空白问答开始；之前保存的内容可从历史中查看。

每条问题最多 1,500 字。电脑浏览器中，Enter 发送，Shift + Enter 换行；中文输入法选词不会误触发送。

可以先试试：

- 大水法由哪里供水？
- 十二生肖兽首有什么功能？
- 海晏堂建于哪一年？

## 等待与阅读回答

发送后会显示圆圆等待动画。回答到达后，正文逐步显示；这是一种阅读效果，并不意味着每个字都在单独重新检索。

根据问题和可用史料，回答会展示正文、圆明园故事、史实依据或引用来源。故事与来源直接呈现，不需要先点开隐藏的说明。不同问题的信息完整程度可能不同；史料不足时应以页面给出的说明为准。

不要把流畅的表述当作确定的史实。涉及具体年代、作者或建筑细节时，结合引用资料阅读。

## 查看、搜索和删除历史

1. 点击问答页右上角 **历史**。
2. 在历史窗口中搜索问题或内容，选择一段记录恢复。
3. 恢复后直接阅读已保存的回答，不会再次自动发送问题。
4. 不需要的记录可以删除；若界面提供撤销提示，可在提示仍显示时撤销。

历史保留最近 **30 段对话**，每段最多保存 **40 次提问**，并随时光账号同步。本机缓存可以帮助再次打开时快速显示，但跨设备恢复仍需连接服务并登录原账号。

## 回答失败怎么办？

先确认顶部连接状态。错误提示中的 **重新提问** 会再次发送该问题；如果连接未恢复，先前往 **我的 → 服务连接**。没有成功取得的回答不会被伪装为已完成。

动画偏多时，可在{ref}`我的资料 <profile>`中关闭圆圆小动画。开启系统“减少动态效果”时，应用也会减少相应动画。
