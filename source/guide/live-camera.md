# 实时相机

到达大水法现场后，可以使用相机查看实时复原。首次体验建议先用[云端示例](restoration.md)确认服务和播放器工作正常。

## 开启前选择计算方案

进入 **我的 → 实时复原方案**，选择以下一种方式。设置在**下一次开启相机**时生效，保存在这台设备上。

|  | 手机协同（默认） | 云端计算 |
| --- | --- | --- |
| 手机承担 | 连续跟踪与模型绘制 | 采集视频、解码和显示结果 |
| 服务器承担 | 间隔关键帧定位与校正 | 跟踪、绘制并回传视频 |
| 首次准备 | 下载约 33 MB 模型与跟踪工具 | 无需下载复原模型 |
| 显示特点 | 连续画面不逐帧等待服务器返回 | 显示受网络往返与编码影响 |
| 适合 | 手机图形能力较好，希望减少网络等待 | 手机本机绘制较慢或负担较大 |

手机协同仍需联网完成首次定位和丢失后的校正，并不是完整的离线复原。缓存不可用或被系统清理时，模型可能需要重新准备。

## 开始取景

1. 返回 **遗迹影像 → 相机预览**。
2. 点击 **准备并开启相机** 或 **开启云端相机**。
3. 按系统提示允许相机权限。手机协同首次使用时，等待模型和工具准备完成。
4. 将镜头对准地图覆盖范围内的大水法，短暂停稳，尽量让拱门、柱子等特征清晰入镜。
5. 出现“已匹配遗址 · 复原预览”后，缓慢移动镜头，观察效果。

画面没有匹配时会先保留实景。距离、角度、遮挡、逆光和快速移动都可能影响定位；对准明显建筑并保持稳定通常更有帮助。

## 观看和停止

实时预览也支持 **透明叠加 / 上下分屏**。云端模式的小窗是当前本机取景，大画面是服务器返回结果，两者可能存在时间差。

点击 **停止相机** 可以立即结束。离开相机页面或将应用切到后台也会停止相机和实时连接；回到前台后需要重新开启。实时预览不录音、不保存相机视频，不能用它直接录制一段复原成片；需要保存视频时使用上传复原。

## 云端一直不出画面

先确认安卓已经更新到 **v0.11.2 / build 16 或更新版本**。本版解决 H.264 首帧缓存导致的等待，并会在兼容问题出现时自动尝试 VP8，无需手动选择视频编码。

如果仍没有画面：

1. 停止相机，检查 **我的 → 服务连接** 是否可用。
2. 尝试加速入口或其他可用网络，再开启相机。
3. 若云端往返仍慢，在“我的”选择 **手机协同** 后重试。
4. 如果系统提示不支持实时编码，更新系统网页组件，或改用手机协同、上传视频。

服务器没有收到有效影像、网络连接中断和设备无法解码是不同问题；以实际提示为准。画面耗时显示只用于观察当前体验，不是所有设备的性能保证。
