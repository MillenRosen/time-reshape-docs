# 遗迹影像

进入 **遗迹影像**，可以直接选择 **云端示例、上传视频、相机预览**。当前复原围绕大水法地图覆盖范围工作，其他景区或任意建筑不一定能定位。

## 选择复原呈现方式

在来源选项下方，可选择 **渐显复原** 或 **直接复原**。渐显会在确认遗址后，用约 5 秒让基座、拱门、柱体和两翼建筑逐步浮现；直接复原则呈现完整建筑。

选择适用于接下来打开的示例或新生成的视频，不会修改已有复原记录。系统开启“减少动态效果”时，默认选择直接复原。两种方式均可调整浓度、切换大屏小窗和下载成片；渐显过程会保留在下载的视频中。云端示例的两种版本均提前计算，选择渐显无需额外等待复原计算。

## 观看云端示例

1. 选择 **云端示例**，从缩略图中选一段视频。
2. 上方预览是原始影像。点击 **观看复原示例**，打开已经计算好的复原结果。
3. 在全屏预览中播放视频，切换对比方式或拖动进度。

当前提供 5 段示例。它们在服务器提前生成，观看时无需重复计算；网络仍需下载视频，首次缓冲是正常的。如果示例正在随模型更新准备，按钮会暂时不可用，准备完成后再观看。

## 上传自己的视频

1. 切换到 **上传视频**，点击 **从设备选择**。
2. 选择包含大水法遗址的视频，先在本机预览。
3. 可调整“生成时的叠加浓度”。前景遮挡为可选实验功能，人物边缘可能漏挡。
4. 点击 **生成复原视频** 后，文件才开始校验、上传并创建任务。
5. 等待排队、复原及封装完成，再查看结果。

| 项目 | 当前范围 |
| --- | --- |
| 文件 | MP4、MOV、WebM 等常见视频容器；实际解码能力以服务校验为准 |
| 大小与时长 | 页面标注 100 MB 以内；实际限制 100 MiB，最长 90 秒 |
| 内容 | 包含地图覆盖范围内、可识别的大水法遗址特征 |
| 成片 | 最高长边 960 像素、30 帧/秒；低帧率输入不强行升帧率 |
| 音频 | 输出为无声复原视频 |
| 保留时间 | 上传文件、任务记录和成片保留 7 天，可主动删除 |

上传阶段离开页面会停止上传，重新选择同一文件可继续已确认的进度。**任务已经提交服务器后**，离开页面不会停止计算，可以稍后在复原记录中查看。

```{figure} ../_static/images/app-restoration.webp
大屏显示 100% 复原画面，缩小后的右上角小窗保留同一帧原片，并避开顶部操作按钮。
```

| 方式 | 操作与用途 |
| --- | --- |
| 透明叠加 | 拖动“复原画面浓度”，观察原始遗迹与复原模型的重合情况 |
| 大屏小窗 | 大屏固定显示 100% 复原，小窗显示同帧原片；不受透明度滑块影响 |

两种方式比较的是同一来源帧；切换布局不会重新生成视频。播放器可以暂停、拖动进度，并在支持时切换 **流畅 · 省流量 / 高清**。网络较慢时优先使用流畅画质。

画面默认等比例铺满屏幕，边缘可能被裁切；点击右上角 **完整** 可显示完整画面，再点击 **铺满** 恢复。横屏观看横向视频，可以同时获得更大的画面与更完整的建筑视野。

滑块与播放操作位于下方半透明区域，右上角眼睛按钮可以隐藏或恢复控件。左上角返回按钮退出全屏并暂停视频，播放进度会保留；点击 **全屏观看** 可继续查看。浏览器返回键和桌面 Escape 键也可退出。

## 保存成片和处理报告

点击 **下载成片**，按当前浓度保存无声 MP4；100% 为完整复原。大屏小窗导出大屏，不含原片小窗。首次导出某个比例需短暂合成，之后复用缓存。下载保留完整画幅、帧率和时长；**查看复原说明** 可下载定位报告。按系统下载提示保存文件即可。

“已定位”表示影像匹配成功，不代表历史细节与几何位置都经过核验。部分片段未定位时保留原画面，报告可帮助查看对应时间。

## 我的复原记录

展开页面下方 **我的复原记录**，可以查看完成、处理中或失败的任务。正在处理的任务可以取消；终止的记录可以删除。删除操作会一并删除该账号下对应的服务器记录与成片。

换设备后，登录同一时光账号可查看仍在保留期内的记录。需要长期保存的成片，请在 7 天内下载到自己的设备。
