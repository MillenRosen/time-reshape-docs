# 账号与历史

首次成功连接服务时，应用会自动创建时光账号，不需要先填写注册表。以后在同一安装或同一浏览器站点再次进入，会沿用已保存的登录状态。

## 登录用户名和昵称

| 名称 | 用途 | 能否修改 |
| --- | --- | --- |
| 登录用户名 | 在其他设备登录、找回资料和历史 | 固定，在“我的时光账号”中复制 |
| 昵称 | 首页问候和个人资料的显示名称 | 可以在资料设置中修改 |
| 头像 | 个性化展示 | 可以选圆圆头像或设备图片 |

同一设备不等于永远只有同一个账号：不同浏览器、不同网站入口、清除数据或重新安装后，可能产生新的本机登录状态。找回旧资料应使用原登录用户名，而不是新页面自动分配的账号。

## 在另一台设备找回

1. 在新设备安装应用或打开网页，先连接服务。
2. 进入 **我的 → 我的时光账号**。
3. 点击 **切换账号**；尚未建立账号时可用 **已有账号登录**。
4. 输入原来的登录用户名与账号密码，点击 **登录并找回历史**。

新账号初始密码为 `123456`。建议使用后尽快通过 **修改密码** 设置个人密码，长度为 6–128 个字符。修改后其他设备需要重新登录。

应用当前不提供邮箱或手机短信找回密码。如果忘记修改后的密码，请联系项目提供者，不要反复注册新账号期待旧历史自动出现。

## 修改头像、昵称和动画

在“我的”顶部资料区域进入编辑，选择圆圆预设头像，或从本机相册选择图片，并填写昵称。保存后个人资料会同步到账号。

资料设置中的圆圆动画选项可以控制小动画；系统的“减少动态效果”设置也会影响动画播放。关闭动画不影响问答和复原功能。

## 哪些内容会同步？

| 内容 | 保存方式 |
| --- | --- |
| 昵称、头像、问答历史 | 跟随账号同步；本机保留缓存以便快速查看 |
| 复原任务与成片 | 服务器按账号保存 7 天，登录同一账号查看 |
| 实时方案、对比方式、服务地址 | 保存在当前设备，换设备后重新设置 |
| 手机协同模型与跟踪工具 | 缓存在当前设备，系统清理后可能重新下载 |

问答历史保留最近 30 段对话，每段最多 40 次提问。本机未同步的更改会等待网络恢复后重试；可点击 **同步记录** 主动同步，并查看是否出现成功提示。

卸载应用、清除应用数据或浏览器站点数据可能删除本机缓存。操作前先确认账号已同步并记录登录信息；尚未上传的本机更改无法保证恢复。
