# 连接服务

界面保存在手机里，并不意味着问答和复原可以完全离线。当前应用的服务连接负责发送问题、同步资料、获取视频以及调用复原计算。

## 安卓安装版

打开 **我的 → 服务连接**：

1. 在 **连接方式** 中优先选择 **加速入口**。
2. 输入项目提供者告知的 **服务访问口令**。
3. 点击 **保存并连接**。
4. 出现“已连接，问答与复原可以使用了”后返回对应页面。复原页另有复原服务状态提示。

已保存有效连接时，口令框可以留空。不要把个人时光账号密码填写在此处。

| 连接方式 | 适合什么情况 |
| --- | --- |
| 加速入口 | 日常优先尝试；当前通过 Cloudflare 临时入口访问服务 |
| 备用入口 | 加速地址不可用时尝试；实际速度取决于网络线路 |
| 自定义服务器 | 管理者已提供完整、可达且可信的 HTTPS 应用服务地址 |

### 加速入口变更

点击 **加速入口失效时，查找新入口**。找到新入口后，点击 **保存并连接** 才会开始使用。查找需要备用服务可达；如果查找失败，保留已知可用地址并联系项目提供者。

### 自定义地址怎么填？

选择“自定义服务器”，填写应用服务的 HTTPS 根地址，例如 `https://app.example.com`。不要填写服务器内部的 `127.0.0.1`，也不要在后面拼接问答接口路径。这里需要的是包含问答、账号与复原接口的应用服务。

能通过 SSH 登录某台服务器，不代表手机可以通过 HTTPS 直接连接它。是否经过中转，取决于服务器的公网地址、端口和网络部署条件。

## 网页预览

浏览器打开[预览地址]({{ preview_url }})后，按页面提示输入服务访问口令。网页 **我的 → 服务连接** 中的“问答服务地址”一般保持空白，沿用当前站点提供的连接。

网页这里的自定义项只调整问答连接，不等同于安卓安装版的整个应用服务器设置。

## 两种密码不要混淆

| 名称 | 用途 | 从哪里取得 |
| --- | --- | --- |
| 服务访问口令 | 进入当前体验服务，连接问答和复原 | 项目提供者告知；本手册不公开口令 |
| 时光账号密码 | 跨设备找回个人资料与历史 | 新账号初始为 `123456`，可在“我的”修改 |

## 连接状态的含义

- **问答已连接**：问答服务健康检查通过。
- **配置连接 / 服务暂未连接**：检查入口、口令及网络，保存后重试。
- **复原页的云端状态**：独立表示复原服务能否处理任务；问答在线不代表复原一定在线。
- **记录暂未更新**：后台记录刷新暂时失败，已经加载的影像仍可观看；稍后点击“刷新记录”。
