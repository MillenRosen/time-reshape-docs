# 连接服务

界面保存在手机里，并不意味着问答和复原可以完全离线。当前应用的服务连接负责发送问题、同步资料、获取视频以及调用复原计算。

## 安卓安装版

**v0.12.3 / build 20 起，默认服务无需手动配置。** 打开应用后，本地页面先显示，后台自动尝试已保存的可用入口，并通过固定地址查找新加速入口。连接成功后自动保存地址、完成默认访问验证，首次使用会自动创建时光账号。

看到顶部“问答已连接”即可提问；复原页另有服务状态提示。已有有效登录会话会复用，服务会话过期时尝试自动恢复。断网时本地页面和已缓存记录仍可浏览，恢复联网或返回应用后会重新尝试连接。

若仍未连接，打开 **我的 → 服务连接**，点击 **重新自动连接**；无需再点击“保存并连接”。服务口令被管理员修改时，应用会提示在 **手动连接设置** 输入新口令。个人时光账号密码不应填写在这里。

| 连接方式 | 适合什么情况 |
| --- | --- |
| 自动选择（推荐） | 日常使用；自动尝试已保存入口、查询新加速入口，必要时使用固定备用入口 |
| 固定备用入口 | 明确指定使用备用服务，保留此选择；实际速度取决于网络线路 |
| 自定义服务器 | 在手动设置中填写可信的 HTTPS 地址及对应服务口令；不会被自动替换 |

### 加速入口变更

应用通过固定备用地址查询服务器发布的最新加速入口。临时隧道重新注册时可能产生新网址；短暂网络重连通常会继续使用原地址，没有固定的每日更换周期。已有入口失效时，应用尝试自动发现、验证并切换，无需复制网址。

自动发现仍需要固定服务可达。两个入口均不可用时，请检查手机网络或稍后重试；手动设置保留用于排查。**旧 APK 需要覆盖安装新版**，只刷新网页不会更新手机内的连接逻辑。

### 自定义地址怎么填？

在 **我的 → 服务连接 → 手动连接设置** 选择“自定义服务器”，填写应用服务的 HTTPS 根地址，例如 `https://app.example.com`。不要填写服务器内部的 `127.0.0.1`，也不要在后面拼接问答接口路径。这里需要的是包含问答、账号与复原接口的应用服务。

能通过 SSH 登录某台服务器，不代表手机可以通过 HTTPS 直接连接它。是否经过中转，取决于服务器的公网地址、端口和网络部署条件。

## 网页预览

浏览器打开[预览地址]({{ preview_url }})后，按页面提示输入默认访问密码 **`123456`**。软件包下载页使用同一密码。网页 **我的 → 服务连接** 中的“问答服务地址”一般保持空白，沿用当前站点提供的连接。

网页这里的自定义项只调整问答连接，不等同于安卓安装版的整个应用服务器设置。

本手册中的预览与下载链接通过固定导航地址获取最新入口。安装下载页也会自动读取并显示当前地址；临时网址更换后，重新点击文档按钮即可。固定地址通常可以长期保留，但仍依赖服务器、Tailscale 服务与域名配置正常运行。

## 两种密码不要混淆

| 名称 | 用途 | 从哪里取得 |
| --- | --- | --- |
| 服务访问口令 | 进入当前体验服务，连接问答和复原 | 当前体验服务默认 `123456`；自行部署时以该服务器配置为准 |
| 时光账号密码 | 跨设备找回个人资料与历史 | 新账号初始为 `123456`，可在“我的”修改 |

## 连接状态的含义

- **问答已连接**：问答服务健康检查通过。
- **连接中**：正在自动准备服务连接，本地页面可以正常浏览。
- **未连接 / 服务暂未连接**：检查网络，点击“重新自动连接”；只有提示口令变更或使用自定义服务器时才需手动填写。
- **复原页的云端状态**：独立表示复原服务能否处理任务；问答在线不代表复原一定在线。
- **记录暂未更新**：后台记录刷新暂时失败，已经加载的影像仍可观看；稍后点击“刷新记录”。
