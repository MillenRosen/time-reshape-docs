# 数据与权限

这里说明当前版本何时使用相机、何时上传内容，以及怎样保存和删除记录。

## 相机与视频

- 只有主动开启实时相机时，应用才请求相机权限。
- 实时预览不录音，也不保存相机视频。
- 手机协同向服务器发送定位关键帧；云端计算发送实时视频供服务器处理。
- 选择本机视频后，先在设备上预览；点击 **生成复原视频** 才开始上传。
- 上传复原输出无声成片。前景遮挡是实验选项，不能保证对人物边缘完整遮挡。

## 问答与资料

提问时，问题文本发送给配置的问答服务。问答历史、昵称和头像会随时光账号同步，以便在其他设备恢复。

不要在问题、昵称或上传视频中包含不希望发送给该服务的信息。自定义服务器应使用项目提供者或你信任的服务地址。

## 保存与删除

| 内容 | 当前保留方式 | 删除入口 |
| --- | --- | --- |
| 问答历史 | 最近 30 段；每段最多 40 次提问 | 史实问答 → 历史 |
| 上传文件、复原任务和成片 | 服务器保留 7 天 | 遗迹影像 → 我的复原记录 |
| 昵称与头像 | 跟随账号保存，可修改 | 我的 → 资料编辑 |
| 本机界面、模型和记录缓存 | 受设备存储和系统清理策略影响 | 系统应用或浏览器站点数据设置 |

清除本机数据不会自动删除所有服务器记录。当前界面没有自助注销整个账号的入口，如需处理账号整体数据，请联系项目提供者。

## 本机界面与网络依赖

安卓 APK 包含页面、圆圆素材和界面资源。断网时仍可以打开本机页面、查看可用缓存，但新的问答、账号同步、未缓存的影像及云端复原需要联网。手机协同也需要联网完成定位校正。

Read the Docs 上的这份手册是公开的静态帮助页面；它不要求输入软件的个人密码或服务访问口令，也不会自动连接复原服务。
