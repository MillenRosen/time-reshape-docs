# 模型后台与配准

这一页面向维护模型的人员。普通使用者无需进入后台：手机和网页会使用服务器当前发布的模型。

## 打开管理中心

先通过[网页预览]({{ preview_url }})进入可用的应用地址，完成服务访问验证，再在**同一网址后添加 `/manage/`**。后台需要服务访问权限；个人时光账号密码不是后台管理凭据。

当前管理中心与应用使用同一个服务访问口令，没有独立的管理员角色系统。请只向需要维护系统的人提供管理操作说明。发布模型会影响后续体验，不要把“应用到所有手机”当作普通预览按钮。

## 哪一个模型正在使用？

以页面顶部的**服务器实际运行版本**和“手机应用 · 正式版本”为准，不能只看下拉框中选中的模型。**截至 {{ documentation_date }}，正式版本为 V004 · 多视角配准**，使用原始 V3.1 复原网格。

| 名称 | 含义 |
| --- | --- |
| V3.1 网格 | 复原建筑本体，包含几何与材质 |
| V004 配准 | 将网格放到遗迹坐标中的整体位置、方向与比例 |
| 渐显分区模型 | 为首次出现动画准备的分区资源，与正式配准共同使用 |
| V005 候选 | 当前源码中保留的候选支持，不代表已经正式发布 |
| V002 | 含局部形变的旧方案，已停用，不能重新发布 |

## 先比较，再微调

1. 在 **模型 / 配准方案** 选择要查看的方案，等待三维预览加载。
2. 使用 **遗迹 / 模型** 分屏比较，或切换 **透明叠加**、**调整前 / 后**。
3. 聚焦拱门、左右主柱和两侧建筑，切换正面、左右斜视和侧面；必要时取消“只看立面”观察全景。
4. 使用 **移动、旋转、拉伸** 或数值输入微调。拉伸对整个模型施加，不编辑某根柱子或某段拱门的局部网格；需要保持比例时使用等比设置。
5. 从多个视角再次检查，可用撤销、重做或恢复初始配准比较差异。

地图和相机参照保持固定。坐标单位是地图相对量，不能直接当作米；界面中的旧特征点误差用于辅助观察，不是独立测绘精度。只对齐一个正面视角，不能保证侧面或远近关系也正确。

## 保存不等于发布

| 操作 | 结果 |
| --- | --- |
| 仅保存配准版本 | 创建一份可回溯的版本，手机继续使用原正式模型 |
| 导出当前参数 JSON | 下载当前参数供检查或归档，不自动上线 |
| 应用到所有手机 | 保存当前配准，准备模型与示例，成功后切换正式版本 |

发布期间关注进度和错误提示。准备失败或取消时保留原正式版本；不要靠手改模型文件或正式指针绕过发布流程。发布后检查云端示例、上传复原和实时相机，并核对所选模型是否支持渐显及对应缓存是否就绪。

正在使用旧模型的实时相机会提示重新开启。**已有成片保留生成时的模型**，不会因发布新模型而自动重算。

## 回退与加载问题

回退时，从配准历史载入可用旧版本，确认预览后再次发布。代码回退、模型回退和用户数据恢复是不同操作，不能只替换一个 GLB。

首次加载可能需要下载约 50 MB 的模型及参照资源。若等待过久，检查服务连接并点击 **重新加载预览**；加载失败不代表保存版本已丢失。设备无 WebGL 时无法显示三维画面，应换用支持 WebGL 的浏览器完成视觉检查。

进程、显卡与服务就绪问题，请看[服务台与资源管理](service-hub.md)。
